# Sparklin — Site multi-pages Netlify

## Déploiement Netlify
1. Dézipper le fichier
2. Sur netlify.com → "Add new site" → "Deploy manually"
3. Glisser-déposer le dossier `sparklin-multipage/`
4. En ligne en < 1 minute

## Structure
Chaque page = un dossier avec son `index.html`.
CSS/JS partagés dans `assets/`.

## Formulaire de contact
Le formulaire utilise **Netlify Forms** (attribut `data-netlify="true"`).
Activé automatiquement à l'upload, sans configuration supplémentaire.
